# Validador de Cadastro
Validador de Cadastro é uma aplicação web que permite validar dados de formulários de cadastro, garantindo que as informações inseridas pelos usuários atendam a critérios específicos antes de serem enviadas.

## 📝 Funcionalidades
- Validação de campos obrigatórios.
- Verificação de formatos de e-mail e senha.
- Feedback visual para campos inválidos.
- Interface amigável e responsiva.

## 💻 Tecnologias Utilizadas
- HTML5
- CSS3
- JavaScript

## 📁 Estrutura do Projeto
```
Validador-Cadastro/
├── index.html
├── cadastro.js
├── style.css
├── default.css
├── upload.html
├── upload.js
├── upload.css
└── img/
```
- index.html: Página principal com o formulário de cadastro.
- cadastro.js: Script responsável pela validação dos dados do formulário.
- style.css e default.css: Estilos aplicados à interface.
- upload.html, upload.js, upload.css: Funcionalidades relacionadas ao upload de arquivos.
- img/: Pasta contendo imagens utilizadas no projeto.

## 🚀 Como Executar

1. Clone o repositório:
```
git clone https://github.com/Brunogarbs/Validador-Cadastro.git
cd Validador-Cadastro
```
